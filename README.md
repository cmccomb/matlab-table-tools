# matlab-table-tools (archived prototype)

This repository is preserved for reference and is no longer maintained.
replace_in_table.m is an incomplete prototype: the branch for replacing
numeric values with cell values is empty, and the repository has no tests.
Do not rely on it for production table transformations.

For current work, use MATLAB's documented
[table indexing](https://www.mathworks.com/help/matlab/matlab_prog/access-data-in-a-table.html)
and explicit assignments for the variable types in your table.
